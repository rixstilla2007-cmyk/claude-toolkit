# Как работать со мной

Постоянные правила для всех сессий и проектов. Их ставит `claude-toolkit` (`install.sh` / `install.ps1`) блоком между метками `claude-toolkit:begin/end`. Править — в `user/CLAUDE.md` тулкита: при установке блок перезаписывается, текст вне меток остаётся.

## 1. Язык — русский

Всё, что я вижу, — по-русски: ответы, рассуждения, вопросы `AskUserQuestion` целиком, **поле `description` у каждого вызова инструмента** (его я читаю в запросе разрешения), задания субагентам, списки дел, отчёты. Не переводить: пути, команды, ключи настроек, вывод программ, названия продуктов.

## 2. Ничего не удалять — главное правило

- Не удаляй файлы и папки без моего явного разрешения на эти конкретные файлы. «Да, продолжай» в ответ на другой вопрос — не разрешение.
- Даже с разрешением не удаляй физически: перенеси в подпапку `_Удалить` рядом, сохранив имя. Когда её чистить — решаю я.
- Перед перезаписью файла целиком посмотри, что в нём, и положи копию в `_Архив` рядом или копию с датой в имени.
- Хук `~/.claude/hooks/no_delete.py` блокирует `rm`, `Remove-Item`, `del` вне Temp, а также `git clean`, `git reset --hard`, `git checkout --`, `git restore`, `git stash drop/clear`, `git branch -D`, `robocopy /MIR`. Временный файл удалить можно, если в самой команде полный путь в Temp — без переменных и `..`.
- Хук `sekrety_git.py` не пускает ключи и токены в `git commit` / `git push`. Сработал — убери секрет из файла (в `.env`, который в `.gitignore`).
- **Хук запретил — не обходи его другой командой, скажи мне.**

## 3. Факты

Не выдумывай источники, ссылки, цифры, функции программ. Не знаешь — скажи или найди и покажи, откуда взял. Цифры, даты, версии, цены, цитаты проверяй по источнику; написал по памяти — пометь.

## 4. Экономия лимита

Лимит сгорает не на ответах, а на перечитывании контекста: каждый запрос заново читает всю переписку.

- **Новая тема — новая сессия** (`/clear`). Начинаю другую задачу в старом чате — напомни одной строкой.
- **Одна задача — одно окно.** Контекст выше ~180 тыс. токенов, а задача не кончилась — скилл `peredacha` (`00 ПЕРЕДАЧА.md`, потом `/clear` и продолжение по файлу). Размер контекста и перерывы отслеживает хук `razmer_konteksta.py` и подсказывает сам.
- **Перерыв больше часа — кэш истёк**: следующий запрос заново записывает весь контекст. К большой сессии после перерыва лучше вернуться через `peredacha`.
- Модель меняй в начале сессии, после сжатия или после перерыва, а не посреди горячей сессии: у каждой модели свой кэш.
- Субагенты на Pro — только по моей просьбе (вызов `assemble-team` и есть просьба), не больше двух сразу, десятки картинок им не отдавать.
- Не перечитывай файлы, которые уже в контексте; не дублируй длинный вывод команд. Большие папки и выгрузки не читай целиком — ищи нужное.
- Описания скиллов и схемы MCP висят в каждом запросе: редкие скиллы — `skillOverrides` → `name-only` в `settings.json`, что занимает место — `/context`.

## 5. Windows

- PowerShell 5.1: нет `&&`, `||`, `??`, `head`/`tail`/`which`/`touch` — пиши `;` + `if ($?)`, `Select-Object -First N`, `Test-Path`.
- Кодировки: `.ps1` с кириллицей — UTF-8 с BOM, JSON — UTF-8 без BOM. Меняешь файл — сохрани его кодировку.
- Git Bash: аргумент с `/` в начале превращается в путь — ставь `MSYS_NO_PATHCONV=1`; Python с русским выводом — `PYTHONIOENCODING=utf-8`. Кириллицу и код с регулярками и путями передавай файлом через Write, а не аргументом команды.

## Compact instructions

При сжатии контекста сохранять: исходную просьбу (дословно, если короткая) и все мои решения и ответы на вопросы; пути созданных и изменённых файлов и где лежат копии; что проверено и чем, а что не проверено; ошибки и как их обошли; незавершённые задачи и следующий шаг. Не сохранять: сырой вывод команд и содержимое прочитанных файлов (оставить путь и вывод из них), промежуточные рассуждения.
